# Codex Quota Viewer Windows Tray 0.0.2

## Highlights

- Adds saved ChatGPT/API account management to the Windows tray app.
- Adds a Windows Accounts settings tab and `All Accounts` tray submenu.
- Keeps Windows package metadata on the independent `0.0.2` release line.

## Notes

The macOS app remains on the `1.1.0` release line. Windows account activation in
this release writes directly into the resolved Codex home; full Safe Switch,
restore points, rollback, and thread/provider repair remain planned follow-ups.

# Codex Quota Viewer Windows Tray 0.1.0

## Highlights

- Updates the Windows tray app to version `0.1.0`.
- Fixes the quota refresh flow for current Codex app-server protocol changes.
- Prevents background Codex and Session Manager helper processes from opening
  visible cmd windows.

## Notes

The macOS app remains on its independent release line. This Windows release keeps
the tray app focused on account switching, quota display, settings, and the
bundled Session Manager.
